# Economic Impact Assessment: Modular Housing under the National Development Plan

## Illustrative Scenario 2026-2029

### Project Overview

This Economic Impact Assessment evaluates Ireland's modular housing delivery under the National Development Plan (NDP), incorporating verified April 2026 data on completions, costs, VAT rates, corporation tax incentives, and pending policy decisions.

### Key Results

| Metric | Value |
| :--- | :--- |
| Total homes delivered (2025-2029) | 191,248 |
| Total investment | €70.1 billion |
| Total GVA | €7.0 billion |
| Total direct jobs | 119,774 person-years |
| Total indirect jobs | 179,661 person-years |
| **Total jobs supported** | **299,435 person-years** |
| Total exchequer return | €10.8 billion |
| Net Present Value (5-year) | €74.7 billion |

### Key Policy Assumptions

| Policy Measure | Status |
| :--- | :--- |
| VAT on new apartments | 9% (until 31 Dec 2030) |
| Corporation tax deduction | 125% (max €50k/unit, until 31 Dec 2030) |
| Rent-a-room scheme | €14,000 tax-free |
| Modular planning exemption | Proposed – pending Cabinet approval |

### Key Findings

- Modular construction is **50% faster**, **15-20% cheaper**, and produces **66% less waste**
- NPV of €74.7 billion over 5 years (4% discount rate)
- 299,435 total jobs supported (direct + indirect)
- €10.8 billion total exchequer return

### Limitations

- 2028-2029 figures are illustrative scenarios, not forecasts
- Indirect multipliers based on international benchmarks (no recent Irish data)
- Modular planning exemption is proposed, not yet enacted
